# АВА-занятия

Внутренний сервис коррекционного центра: специалист отмечает пробы на занятии,
сервис считает проценты, подсказывает задержку, отмечает освоенные цели и готовит
отчёт родителям.

## Запуск

```bash
npm install
npm run dev          # разработка, http://localhost:3000
```

Рабочая версия (быстрее, с режимом приложения на телефоне):

```bash
npm run build && npm start
```

С телефона в той же сети Wi-Fi — по адресу компьютера, например `http://10.0.0.5:3000`.

## Проверки

```bash
npm test     # правила методики на примерах с бумажных бланков
npm run lint
npm run build
```

## Настройки

Скопируйте `.env.example` в `.env.local` и заполните:

| Переменная | Где взять |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | там же, ключ `sb_publishable_…` |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API keys, **ключ должен быть выдан на workspace** |

`.env.local` в git не попадает.

## Где что лежит

```
src/app/(app)/          экраны после входа: дети, карточка, занятие, навыки, сотрудники
src/app/login/          вход
src/lib/rules/          правила методики: проценты, задержки, освоение, ротация (+ тесты)
src/lib/offline/        очередь отметок без интернета
src/lib/ai/             черновики отчётов (только сервер)
src/lib/supabase/       подключение к базе
supabase/migrations/    таблицы и права доступа
supabase/functions/     серверная функция для учётных записей сотрудников
```

## Как начать новому разработчику

1. **Код и запуск**

   ```bash
   git clone <адрес репозитория> && cd aba-service
   npm install
   cp .env.example .env.local
   ```

2. **Своя база.** Не подключайтесь к боевой: там медицинские данные несовершеннолетних.
   Заведите бесплатный проект на supabase.com, затем:

   ```bash
   npm i -g supabase                 # или npx supabase
   supabase link --project-ref <ref вашего проекта>
   supabase db push                  # накатит supabase/migrations/
   ```

   Схема, права доступа (RLS) и таблицы появятся сами. Примеры навыков и фей — в
   `supabase/seed.sql`, выполните его в SQL-редакторе Supabase.
   Сотрудников заводит серверная функция: `supabase functions deploy staff-admin`.
   Первого руководителя проще создать в панели Supabase: Authentication → Add user,
   затем в SQL-редакторе задать роль:

   ```sql
   update auth.users
   set raw_app_meta_data = raw_app_meta_data || '{"staff_role":"supervisor"}'
   where email = 'ваша@почта';
   ```

3. **Свой ключ Claude.** console.anthropic.com → API keys. Ключ должен быть выдан
   на workspace, иначе запросы возвращают ошибку 400. Поставьте себе месячный лимит расходов.

4. **Перед отправкой кода** прогоните три проверки:

   ```bash
   npm test          # правила методики на примерах с бумажных бланков
   npm run lint
   npm run build
   ```

   Правила методики (проценты, задержки, освоение, ротация) меняются только в
   `src/lib/rules/` и только вместе с тестами: цифры сверены с бланками центра.

5. **Чего не делать:** не писать ключи в код, не обходить проверку прав на стороне
   браузера (права проверяет база), не публиковать на боевой адрес без согласования —
   публикацию делает владелец проекта.
