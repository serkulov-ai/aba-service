# Публикация

**Адрес**: https://aba-zanyatiya.netlify.app
**Площадка**: Netlify, команда «serkulov's team», проект `aba-zanyatiya`
**Панель управления**: https://app.netlify.com/projects/aba-zanyatiya
**Стоимость**: 0 ₸ в месяц (бесплатный тариф) + расход на ИИ-черновики (~1 ₸ за отчёт)

## Обновить сайт после правок

```bash
cd ~/Desktop/aba-service
npm run build && npm test          # убедиться, что всё цело
npx netlify deploy --build --prod  # выложить
```

Первый раз попросит войти в Netlify — откроется браузер.

## Откатиться на прошлую версию

Панель Netlify → **Deploys** → выбрать предыдущую сборку → **Publish deploy**.
Занимает секунды, код на компьютере при этом не меняется.

## Ключи и настройки

Значения хранятся в Netlify (Project configuration → Environment variables),
в коде и в git их нет. На компьютере те же значения лежат в `.env.local`.

| Переменная | Что это | Где взять заново |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | адрес базы | Supabase → Project Settings → API |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | публичный ключ базы | там же |
| `ANTHROPIC_API_KEY` | ключ Claude для черновиков | console.anthropic.com → API keys (ключ должен быть выдан на workspace) |

После смены любого значения нужно выложить сайт заново — сборка подхватывает их во время сборки.

## Что настроено на площадке отдельно

- **Доступ «только для команды» выключен** (`sso_login: false`) — иначе ссылка требовала бы
  входа в аккаунт Netlify.
- **Значок «Powered by Netlify» выключен** (`built_with_badge_enabled: false`) — он перекрывал
  кнопки «+ С подсказкой» и «Неверно» на экране занятия.

## Ограничения этой публикации

Сервис открыт демонстрационно, с выдуманными детьми. До работы с настоящими детьми
нужно закрыть пункты из `SECURITY.md`: хранение данных в Казахстане, ежедневные копии базы
(Supabase Pro), удаление демо-аккаунтов, закрытие самостоятельной регистрации.
